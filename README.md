# Objetivo
Lista de Exercícios da disciplina de POO (Programação Orientada a Objetos) da UFAM - ICET, cujo objetivo é praticar os conceitos de programação orientada a objetos, abordando temas como classes abstratas com ABC e implementação de classes utilizando Protocol com Duck Typing.

# Tutorial
## Pré-Requesitos
- Uma máquina com Python versão 3.14.4 ou superior instalada;
- Um ambiente de desenvolvimento (IDE) para execução dos códigos, como PyCharm ou Visual Studio Code.

## Como rodar
Todos os códigos estão organizados em pastas dentro do repositório. Cada pasta contém dois arquivos: um arquivo com todas as classes e funções sem implementação e outro arquivo chamado main.py, responsável pela execução dos testes do código.
